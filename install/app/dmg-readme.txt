КАК ОТКРЫТЬ Clip It!  (English below)

Один Clip It! для любого Mac — с Apple silicon (M1 и новее) и с Intel: он сам запускает свою версию.

1. Перетащите значок Clip It! на папку «Программы» (Applications) рядом с ним.
2. Откройте «Программы» и дважды щёлкните Clip It! macOS скажет, что не может проверить программу,
   и не откроет её. Нажмите «Готово».
3. Откройте «Системные настройки» → «Конфиденциальность и безопасность». Внизу будет строка
   «Clip It! заблокирована…» — нажмите «Всё равно открыть», введите пароль от Mac и ещё раз «Открыть».
   (На macOS 14 вместо шага 3 можно нажать на Clip It! правой кнопкой мыши → «Открыть» → «Открыть».)
Так нужно только в первый раз: дальше Clip It! открывается обычным щелчком.

Почему macOS предупреждает: у Clip It! пока нет подписи Apple. Подпись появится при первой возможности,
тогда это предупреждение пропадёт. Код Clip It! открыт: https://github.com/yuriti/clipit

При первом запуске Clip It! проверит компьютер и предложит скачать распознавание речи для вашего языка
(«Проверка компьютера» → «Исправить»). Это нужно один раз: от 0,9 до 2,5 ГБ.

Помощь: https://github.com/yuriti/clipit/blob/main/docs/guide/install.md


HOW TO OPEN Clip It!

One Clip It! for every Mac, with Apple silicon (M1 and newer) or Intel: it starts the right version by itself.

1. Drag the Clip It! icon onto the Applications folder next to it.
2. Open Applications and double-click Clip It! macOS says it cannot check the app and does not open it.
   Click «Done».
3. Open System Settings → Privacy & Security. At the bottom there is a line «Clip It! was blocked…»:
   click «Open Anyway», enter your Mac password and click «Open» once more.
   (On macOS 14 you can instead right-click Clip It! → «Open» → «Open».)
Only the first time: after that Clip It! opens with a normal click.

Why macOS warns: Clip It! has no Apple signature yet. It will get one as soon as possible, and then this
warning goes away. Clip It!'s code is open: https://github.com/yuriti/clipit

On the first start Clip It! checks this computer and offers to download speech recognition for your
language («Check this computer» → «Fix»). Once, 0.9 to 2.5 GB.

Help: https://github.com/yuriti/clipit/blob/main/docs/guide/en/install.md
