# 在手机上用 SMTV

SMTV 在电脑上运行时，你可以用手机观看切片、发起任务、跟进进度。手机上什么都不用装：在浏览器里打开就行。

1. 在 SMTV 中点击左下角的**手机**（**phone**）按钮。
2. 打开 **Open access from a phone**（允许从手机访问）。
3. 有好几个网络？在 **Address in the network**（网络中的地址）里选你手机所连的那个 Wi-Fi。
4. 用手机相机对准**二维码**，打开链接。

<img src="../../images/phone.png" alt="连接手机：扫描二维码" width="820">

## 需要知道的

- 手机必须和电脑连在**同一个 Wi-Fi** 上。访客网络常常会把设备隔开，手机或电脑上的 VPN 也会造成干扰。
- 第一次使用时，macOS 或 Windows 会询问 SMTV 是否可以接受连接：请**允许**。
- 连接是普通连接，没有加密：**只在家里**使用，千万不要在公共 Wi-Fi 上用。
- 二维码里含有一个密钥；没有它页面打不开。关闭访问会断开所有手机，下次会生成新的二维码。
- 用手机时，电脑必须保持开机。
