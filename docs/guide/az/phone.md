# Telefonda SMTV

SMTV kompüterinizdə işləyərkən kliplərə baxın, sorğular başladın və işi telefonunuzdan izləyin. Telefona heç nə
quraşdırmaq lazım deyil: o, brauzerdə açılır.

1. SMTV-də aşağı soldakı **telefon** düyməsini basın.
2. **Open access from a phone** (Telefondan girişi aç) yandırın.
3. Bir neçə şəbəkə var? **Address in the network** (Şəbəkədə ünvan) bölməsində telefonunuzun qoşulduğu Wi-Fi-ı seçin.
4. Telefonun kamerasını **QR koda** tutun və linki açın.

## Nəyi bilməli

- Telefon kompüterlə **eyni Wi-Fi**-da olmalıdır. Qonaq şəbəkələri çox vaxt cihazları bir-birindən ayırır, telefonda və
  ya kompüterdə VPN isə mane olur.
- İlk dəfə macOS və ya Windows SMTV-nin qoşulmaları qəbul edə bilib-bilməyəcəyini soruşur: **icazə verin**.
- Qoşulma sadədir, şifrələnməyib: onu **yalnız evdə** istifadə edin, heç vaxt ictimai Wi-Fi-da yox.
- Kodun içində açar var; onsuz səhifə açılmır. Girişi söndürmək bütün telefonları ayırır və növbəti dəfə yeni kod
  yaradılır.
- Telefondan istifadə etdiyiniz müddətdə kompüter yanılı qalmalıdır.
