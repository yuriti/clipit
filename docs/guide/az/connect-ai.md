# Hansı Sİ-ni seçməli

SMTV nitqi özü, kompüterinizdə mətnə çevirir. Ən yaxşı anları seçmək üçün isə süni intellektdən (Sİ) — ChatGPT-nin
arxasındakı kimi bir dil modelindən — soruşur. **Settings → AI** (Ayarlar → Sİ) bölməsində üç yoldan **birini** seçin.
Onu istənilən vaxt dəyişə bilərsiniz.

<img src="../../images/ai.png" alt="Settings → AI: Sİ qoşmağın üç yolu" width="820">

| | ⭐ Hesab vasitəsilə | 🔑 Öz açarınız | 💻 Pulsuz, kompüterinizdə |
|---|---|---|---|
| Nə edirsiniz | Daxil olun, balansı artırın | Xidmətin saytında açar alın, yapışdırın | Ollama və ya LM Studio və model quraşdırın |
| Qiyməti | İstifadəyə görə balansdan ödəniş | Xidmətin qiymətləri; bəzilərinin pulsuz planı var | Pulsuz |
| Klip keyfiyyəti | Ən yaxşı (güclü bulud modelləri) | Seçdiyiniz model qədər yaxşı | Daha zəif |
| Kompüter | İstənilən | İstənilən | Güclü videokart: 8–16 GB video yaddaş |
| Twitch və YouTube linkləri | Bəli | Yalnız əlavə olaraq hesabla (və ya fayl) | Yalnız əlavə olaraq hesabla (və ya fayl) |
| Bələdçi | [Hesab](account.md) | [Açarı haradan almaq olar](get-a-key.md) | [Kompüterinizdə pulsuz Sİ](free-ai-on-your-computer.md) |

**Əmin deyilsiniz?** Hesabı seçin: heç nə quraşdırmaq lazım deyil. Heç nə xərcləmək istəmirsiniz və oyun kompüteriniz
var? Əvvəlcə pulsuz yolu sınayın. Artıq OpenAI, Claude və ya Gemini üçün ödəyirsiniz? Açarınızdan istifadə edin.

**Açar nədir?** Sİ xidməti üçün uzun parol («API açarı»). Qeydiyyatdan keçdikdən sonra xidmətin saytı onu sizə verir.
SMTV onu yalnız kompüterinizdə saxlayır və yalnız həmin xidmətə göndərir.

**Yayımım hara gedir?** Video kompüterinizdə qalır. Yalnız yayımın mətni seçdiyiniz Sİ-yə gedir. Kompüterinizdəki
pulsuz Sİ ilə heç nə kənara çıxmır.

**Digər yollar.** **Other ways** (Digər yollar) bölməsində SMTV həmçinin ChatGPT (Codex) və ya Claude (Claude Code)
abunəsindən istifadə edə bilər. Bunu tövsiyə etmirik: bu xidmətlərin qaydaları abunədən başqa proqramların istifadəsini
qadağan edə bilər.
