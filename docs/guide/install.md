# Установка SMTV

Скачайте один файл, откройте его — и появится значок **SMTV**. Всё нужное уже внутри. Пароль администратора не нужен.

| Ваш компьютер | Скачать | Размер |
|---|---|---|
| **Windows 10 или 11** (64-битная) | [SMTV для Windows](https://github.com/yuriti/clipit/releases/latest/download/SMTV-windows-setup.exe) | около 130 МБ |
| **Mac** — Apple silicon (M1 и новее) или Intel, macOS 13+ | [SMTV для Mac](https://github.com/yuriti/clipit/releases/latest/download/SMTV-mac.dmg) | около 270 МБ |

Все версии и их контрольные суммы — на [странице выпуска](https://github.com/yuriti/clipit/releases/latest).

**Почему в первый раз система предупреждает.** У SMTV пока нет цифровой подписи. Подпись для Windows появится чуть
позже, для macOS — при первой возможности; тогда это предупреждение пропадёт. Код SMTV открыт: любой может прочитать,
что он делает.

## Windows

1. Скачайте **SMTV для Windows** (файл `SMTV-…-windows-x64-setup.exe`) и откройте его.
2. Windows покажет синее окно **«Система Windows защитила ваш компьютер»**. Нажмите **Подробнее**, затем **Выполнить в
   любом случае**.
3. Установщик задаст пару вопросов (язык, значок на рабочем столе) — нажмите **Далее** и **Установить**.
4. В конце оставьте галочку **Запустить SMTV** и нажмите **Завершить**. В следующий раз запускайте SMTV из меню
   **«Пуск»** (или со значка на рабочем столе).

Установщик ставит SMTV в вашу папку пользователя; SMTV появится в **Параметры → Приложения**, там же его можно удалить.

**Без установки:** скачайте [ZIP-архив](https://github.com/yuriti/clipit/releases/latest/download/SMTV-windows.zip),
распакуйте куда угодно (например, в «Документы») и откройте **Start SMTV** в папке `SMTV`. Такая копия не обновляется
сама: новая версия — это новый архив.

### Windows 11: Smart App Control

Если включено **Smart App Control** («Интеллектуальное управление приложениями»: Безопасность Windows → Управление
приложениями и браузером), Windows блокирует программы без подписи целиком, и кнопки «всё равно запустить» там нет.
Отключать его ради SMTV не нужно. Поставьте SMTV одной строкой — так он работает и со Smart App Control:
[одной строкой в терминале](#для-опытных-одной-строкой-в-терминале). Когда у SMTV появится подпись, заработает и
скачанный файл.

## Mac

1. Скачайте **SMTV для Mac**. Это один файл для любого Mac, с Apple silicon или Intel: SMTV сам запускает версию,
   сделанную под процессор вашего Mac.
2. Откройте скачанный `.dmg`. Откроется окно с SMTV и папкой **«Программы»** (Applications): перетащите **SMTV** на
   **«Программы»**.
3. Откройте **«Программы»** и дважды щёлкните **SMTV**. macOS скажет, что не может проверить SMTV, и не откроет его.
   Нажмите **Готово**.
4. Откройте **Системные настройки → Конфиденциальность и безопасность** и прокрутите вниз. Рядом со строкой «SMTV
   заблокирована…» нажмите **Всё равно открыть**, введите пароль от Mac и нажмите **Открыть**.
   На macOS 14 есть путь короче: правой кнопкой мыши по **SMTV** в «Программах» → **Открыть** → **Открыть**.

Так нужно только в первый раз: дальше SMTV открывается обычным щелчком, из «Программ» или Launchpad. Те же шаги — в
файле «Как открыть» внутри `.dmg`.

## Первый запуск

SMTV проверит компьютер и покажет три шага до первого клипа. Под ними он предложит **распознавание речи для вашего
языка** — то, что превращает речь со стрима в текст. В скачанном файле его нет, потому что каждому языку нужно своё
(0,9–2,5 ГБ). Нажмите **Исправить** и следите за полосой загрузки — или пропустите: первая заявка скачает его сама.

**Что нужно:** минимум 5 ГБ свободного места, для 6-часового стрима — 20 ГБ; интернет. Видеокарта не нужна.

## Для опытных: одной строкой в терминале

Тот же SMTV, поставленный через [uv](https://astral.sh/uv) — небольшой официальный инструмент для программ на Python —
в вашу папку пользователя. Подходит для **Linux**, для **Smart App Control** и для тех, кому удобнее терминал.
Обновляется из окна так же, как скачанное приложение.

**Windows:** нажмите **«Пуск»**, наберите `PowerShell`, откройте **Windows PowerShell** (синее окно), вставьте строку
(правой кнопкой мыши или Ctrl+V) и нажмите **Enter**:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/yuriti/clipit/main/install/install.ps1 | iex"
```

Если включено Smart App Control, установщик поставит SMTV на подписанный Python с python.org (может предложить его
установить — соглашайтесь) и будет запускать SMTV через него. Если терминал пишет, что не может запустить `smtv`,
запускайте SMTV значком.

**Mac или Linux:** откройте **Терминал** (на Mac: Cmd+Пробел, наберите `Терминал`, Enter), вставьте строку и нажмите
**Enter**:

```bash
curl -LsSf https://raw.githubusercontent.com/yuriti/clipit/main/install/install.sh | sh
```

Подождите, пока он напишет, что всё готово (2–10 минут). SMTV откроется сам; значок **SMTV** — в меню «Пуск» на
Windows, в «Программах» на Mac, в меню приложений на Linux. При таком способе SMTV в первый раз предложит поставить
**ffmpeg** (программу для видео) кнопкой «Исправить»; в скачанном файле выше он уже внутри.

Оба установщика короткие и открытые: [install.ps1](../../install/install.ps1), [install.sh](../../install/install.sh).

## Если система предупреждает

- **Windows: «Система Windows защитила ваш компьютер»** (SmartScreen). Нажмите **Подробнее**, затем **Выполнить в
  любом случае**.
- **Windows 11: Smart App Control блокирует SMTV.** Пока у SMTV нет подписи, ставьте его
  [одной строкой в терминале](#для-опытных-одной-строкой-в-терминале).
- **Windows: брандмауэр спрашивает**, можно ли SMTV пользоваться сетью. Разрешите для **частных** сетей: это нужно,
  чтобы открыть SMTV на телефоне. Если телефон не нужен, можно отказать.
- **Mac: «Не удаётся открыть SMTV»**, «Apple не может проверить…» или «не удаётся проверить разработчика». Откройте
  **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Всё равно открыть** рядом
  с SMTV.
- **Mac: «Разрешить SMTV принимать входящие подключения?»** — разрешите, если хотите пользоваться SMTV с телефона.
- **Антивирус** ругается? SMTV новый и пока без подписи, поэтому некоторые антивирусы к нему осторожны. Его код открыт,
  а контрольные суммы каждого файла лежат на [странице выпуска](https://github.com/yuriti/clipit/releases/latest)
  (`SHA256SUMS.txt`).
