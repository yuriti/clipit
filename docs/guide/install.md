# Установка Clip It!

Скачайте один файл и откройте его. Всё нужное уже внутри. Пароль администратора не нужен.

| Ваш компьютер | Скачать | Размер |
|---|---|---|
| **Windows 10 или 11** (64-битная) | [Clip It! для Windows](https://github.com/yuriti/clipit/releases/latest/download/SMTV-windows.zip) (ZIP) | около 100 МБ |
| **Mac** — Apple silicon (M1 и новее) или Intel, macOS 13+ | [Clip It! для Mac](https://github.com/yuriti/clipit/releases/latest/download/SMTV-mac.dmg) | около 270 МБ |

Все версии и их контрольные суммы — на [странице выпуска](https://github.com/yuriti/clipit/releases/latest).

**Почему в первый раз система предупреждает.** У Clip It! пока нет цифровой подписи. Подпись для Windows появится чуть
позже, для macOS — при первой возможности; тогда это предупреждение пропадёт. Код Clip It! открыт: любой может прочитать,
что он делает.

Раньше программа называлась SMTV: если она у вас уже стоит, новая версия встанет на её место, настройки и
клипы останутся.

## Windows

Установщика нет: Clip It! для Windows — это папка, которую вы распаковываете и запускаете.

1. Скачайте **Clip It! для Windows** — ZIP-архив `SMTV-windows.zip`.
2. Нажмите на него правой кнопкой → **Извлечь всё** → выберите папку (например, «Документы») → **Извлечь**.
3. Откройте папку `ClipIt`. В ней **ClipIt.exe**, файл «Как запустить Clip It!», папка `app` с частями программы (её не
   трогайте) и папка `Clips`. Дважды щёлкните **ClipIt.exe** — у него значок Python, так и должно быть, — откроется окно
   Clip It! Если Windows покажет синее окно **«Система Windows защитила ваш компьютер»**, нажмите **Подробнее**, затем
   **Выполнить в любом случае**.

**Всё хранится в этой папке**: настройки, ключи нейросетей, модели распознавания речи (около 2,4 ГБ). Готовые клипы — в
папке `Clips`. Ярлыков и файлов в других местах Clip It! не создаёт. Поэтому:

- держите папку целиком на одном месте, например в «Документах»; хотите ярлык — правой кнопкой по **ClipIt.exe** →
  **Отправить** → **Рабочий стол (создать ярлык)** (в Windows 11 сначала **Показать дополнительные параметры**);
- не передавайте папку другим людям: в ней ваши ключи;
- не кладите её в папку, которую синхронизирует OneDrive, и в «Program Files» (туда нельзя записывать — Clip It! скажет
  об этом).

**Обновление** — из окна: Clip It! скачает новую версию и заменит программу в этой же папке; настройки и клипы не
трогаются. **Удалить** — удалите папку `ClipIt` целиком, или в окне: **Настройки → Система → Удалить Clip It! с
компьютера**.

Если у вас стоит прежняя версия (SMTV, с установщиком), при первом запуске Clip It! предложит один раз скопировать её
настройки и ключи в новую папку. Старую версию удалите как обычно: **Параметры → Приложения → SMTV → Удалить**.

### Windows 11: Smart App Control

Если включено **Smart App Control** («Интеллектуальное управление приложениями»: Безопасность Windows → Управление
приложениями и браузером), Windows не пускает программы без подписи, и кнопки «всё равно запустить» там нет. Отключать
его ради Clip It! не нужно:

1. Возьмите **ZIP** и откройте **ClipIt.exe** (шаги выше) — так Clip It! работает и со Smart App Control: ClipIt.exe —
   это официальный Python, подписанный его авторами (Python Software Foundation), а подписанные программы Windows пускает.
2. Если не откроется и он — поставьте Clip It! [одной строкой в терминале](#для-опытных-одной-строкой-в-терминале).

## Mac

1. Скачайте **Clip It! для Mac**. Это один файл для любого Mac, с Apple silicon или Intel: Clip It! сам запускает версию,
   сделанную под процессор вашего Mac.
2. Откройте скачанный `.dmg`. Откроется окно с Clip It! и папкой **«Программы»** (Applications): перетащите **Clip It!** на
   **«Программы»**.
3. Откройте **«Программы»** и дважды щёлкните **Clip It!**. macOS скажет, что не может проверить Clip It!, и не откроет его.
   Нажмите **Готово**.
4. Откройте **Системные настройки → Конфиденциальность и безопасность** и прокрутите вниз. Рядом со строкой «Clip It!
   заблокирована…» нажмите **Всё равно открыть**, введите пароль от Mac и нажмите **Открыть**.
   На macOS 14 есть путь короче: правой кнопкой мыши по **Clip It!** в «Программах» → **Открыть** → **Открыть**.

Так нужно только в первый раз: дальше Clip It! открывается обычным щелчком, из «Программ» или Launchpad. Те же шаги — в
файле «Как открыть» внутри `.dmg`.

## Первый запуск

Clip It! проверит компьютер и покажет три шага до первого клипа. Под ними он предложит **распознавание речи для вашего
языка** — то, что превращает речь со стрима в текст. В скачанном файле его нет, потому что каждому языку нужно своё
(0,9–2,5 ГБ). Нажмите **Исправить** и следите за полосой загрузки — или пропустите: первая заявка скачает его сама.

**Что нужно:** минимум 5 ГБ свободного места, для 6-часового стрима — 20 ГБ; интернет. Видеокарта не нужна.

## Для опытных: одной строкой в терминале

Тот же Clip It!, поставленный через [uv](https://astral.sh/uv) — небольшой официальный инструмент для программ на Python —
в вашу папку пользователя. Подходит для **Linux**, для **Smart App Control** и для тех, кому удобнее терминал.
Обновляется из окна так же, как скачанное приложение.

**Windows:** нажмите **«Пуск»**, наберите `PowerShell`, откройте **Windows PowerShell** (синее окно), вставьте строку
(правой кнопкой мыши или Ctrl+V) и нажмите **Enter**:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/yuriti/clipit/main/install/install.ps1 | iex"
```

Если включено Smart App Control, установщик поставит Clip It! на подписанный Python с python.org (может предложить его
установить — соглашайтесь) и будет запускать Clip It! через него. Если терминал пишет, что не может запустить `smtv`,
запускайте Clip It! значком.

**Mac или Linux:** откройте **Терминал** (на Mac: Cmd+Пробел, наберите `Терминал`, Enter), вставьте строку и нажмите
**Enter**:

```bash
curl -LsSf https://raw.githubusercontent.com/yuriti/clipit/main/install/install.sh | sh
```

Подождите, пока он напишет, что всё готово (2–10 минут). Clip It! откроется сам; значок **Clip It!** — в меню «Пуск» на
Windows, в «Программах» на Mac, в меню приложений на Linux. При таком способе Clip It! в первый раз предложит поставить
**ffmpeg** (программу для видео) кнопкой «Исправить»; в скачанном файле выше он уже внутри.

Оба установщика короткие и открытые: [install.ps1](../../install/install.ps1), [install.sh](../../install/install.sh).

## Если система предупреждает

- **Windows: «Система Windows защитила ваш компьютер»** (SmartScreen). Нажмите **Подробнее**, затем **Выполнить в
  любом случае**.
- **Windows 11: Smart App Control блокирует Clip It!** Пока у Clip It! нет подписи, возьмите ZIP и откройте **ClipIt.exe**;
  если не поможет — поставьте Clip It! [одной строкой в терминале](#для-опытных-одной-строкой-в-терминале).
- **Windows: брандмауэр спрашивает**, можно ли Clip It! пользоваться сетью. Разрешите для **частных** сетей: это нужно,
  чтобы открыть Clip It! на телефоне. Если телефон не нужен, можно отказать.
- **Mac: «Не удаётся открыть Clip It!»**, «Apple не может проверить…» или «не удаётся проверить разработчика». Откройте
  **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Всё равно открыть** рядом
  с Clip It!
- **Mac: «Разрешить Clip It! принимать входящие подключения?»** — разрешите, если хотите пользоваться Clip It! с телефона.
- **Антивирус** ругается? Clip It! новый и пока без подписи, поэтому некоторые антивирусы к нему осторожны. Его код открыт,
  а контрольные суммы каждого файла лежат на [странице выпуска](https://github.com/yuriti/clipit/releases/latest)
  (`SHA256SUMS.txt`).
