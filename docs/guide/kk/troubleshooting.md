# Бірдеңе дұрыс болмады

## 1. Компьютерді тексеру → Түзету

**Settings → Computer check** (Баптаулар → Компьютерді тексеру) SMTV-ге керектің бәрін қарап, жол-жолымен не дұрыс,
не дұрыс емес екенін айтады. Мәселенің қасында **Fix** (Түзету) түймесі бар: SMTV қолынан келгенін өзі орнатады немесе
жөндейді және не істеп жатқанын көрсетеді.

<img src="../../images/check.png" alt="Settings → Computer check: әр жол өз күйімен және Fix түймесімен" width="820">

| Жолда жазылғаны | Не істеу керек |
|---|---|
| **Video (ffmpeg)** жоқ | **Fix** басыңыз: SMTV өзі пайдаланатын бейне құралы ffmpeg-ті орнатады. |
| **Captions** (субтитрлер) жұмыс істемейді | **Fix** басыңыз: SMTV субтитр сала алатын ffmpeg орнатады. |
| **AI** (ЖИ): ештеңе қосылмаған | **Settings → AI** бөлімінде біреуін таңдаңыз — [қайсысын](connect-ai.md). |
| **Connection to StreamMoment** (StreamMoment-пен байланыс) жоқ | Интернетті тексеріңіз; оны VPN немесе брандмауэр бұғаттауы мүмкін. Файлдар онсыз да жұмыс істейді. |
| **Free space** (бос орын) аз | Дискіде орын босатыңыз: 6 сағаттық стрим өңделу кезінде шамамен 20 ГБ қажет етеді. |
| **Speech to text** (сөзді мәтінге айналдыру): модель жүктелмеген | Ол бірінші сұрауда өзі жүктеледі; немесе **Settings → Speech to text** ішінде **Download** басыңыз. |

Әкімші құпиясөзін қажет ететін түзету ешқашан үнсіз іске қосылмайды: SMTV команда жазылған терминалды ашады, сонда
оның не істейтінін көресіз.

## 2. Жиі кездесетін мәселелер

- **Сілтеме жұмыс істемейді.** Сілтемелер үшін [StreamMoment аккаунты](account.md) керек. Аккаунт жоқ па? Жазбаны
  өзіңіз жүктеп алып, SMTV-ге файл беріңіз.
- **Клип жоқ немесе өте аз.** SMTV тек ЖИ жақсы деп бағалаған сәттерді қалдырады. Қысқа немесе тыныш стрим аз беруі
  мүмкін. Компьютердегі тегін ЖИ бұлттықтан гөрі жақсы сәттерді азырақ табады.
- **«Too many requests»** (сұраулар тым көп). ЖИ сервисіңіздің тегін тарифі шегіне жетті: күтіңіз немесе ақылы
  тарифті не аккаунтты пайдаланыңыз.
- **Телефон SMTV-ді ашпайды.** Бір Wi-Fi, VPN жоқ, брандмауэрде SMTV-ге рұқсат беріңіз — [телефон](phone.md) бетін
  қараңыз.
- **Windows: терминал `smtv` іске қоспайды.** Бұл Smart App Control; SMTV-ді белгішесінен іске қосыңыз.
- **Терезе SMTV-мен байланысын жоғалтты.** Терезені жабып, SMTV-ді қайта ашыңыз.

Тоқтап қалған сұрауды жалғастыруға болады: **Continue** (Жалғастыру) басыңыз — SMTV сол қадамнан жалғастырады және
жасалғанды қайта жасамайды.

## 3. Мәселе туралы хабарлау

Әлі де шешілмеді ме? Бізге айтыңыз — бұл барлығына көмектеседі.

1. **Settings → Computer check → Report a problem** (**Report…** түймесі; ол **Settings → About** ішінде де бар) немесе
   сәтсіз аяқталған сұраудың астындағы түйме.
2. SMTV есепке не кіретінін көрсетеді: нұсқалар, компьютерді тексеру, баптаулар мен логтар. **Кілттер мен токендер
   қиып алынады**, үй қалтаңыз `~` болып көрсетіледі. Құсбелгі қоймасаңыз, сілтемелер мен файл атаулары есепке
   кірмейді.
3. **Save and open GitHub** (Сақтап, GitHub ашу) басыңыз. SMTV мұрағатты сақтайды, ал браузерде қысқаша мазмұны
   толтырылған жаңа issue ашылады. Мұрағатты соған сүйреп апарып, **Submit** басыңыз.

SMTV өзінен-өзі ештеңе жібермейді. Терезесіз: терминалда `smtv report` орындаңыз. Сондай-ақ тікелей
[issue ашуға](https://github.com/streammomenttv/smtv/issues/new?template=bug.yml) болады.
