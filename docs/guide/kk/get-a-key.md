# Кілтті қайдан алуға болады

**Кілт** («API кілті») — SMTV-ге сіздің атыңыздан ЖИ сервисін пайдалануға мүмкіндік беретін ұзын құпиясөз. Оны
тіркелгеннен кейін сервис сайтынан аласыз. SMTV оны тек компьютеріңізде сақтайды және тек сол сервиске жібереді; ол
логтарда да, мәселе туралы есептерде де ешқашан көрінбейді.

> Бағалар мен тегін тарифтер өзгереді. Мұнда жазылғаны сервистердің өз беттерінде **23.11.2026** тексерілді — бастамас бұрын сервистің бетін тексеріңіз.

тым көп) деп жауап береді, ал SMTV күтеді немесе тоқтайды. 6–12 сағаттық стрим үшін ақылы тариф немесе
[аккаунт](account.md) жақсырақ.

## Мысал: тегін Gemini кілті қадам бойынша

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) ашып, Google аккаунтымен кіріңіз.
2. Сұраса, шарттарды қабылдаңыз.
3. **Create API key** басыңыз. Кілтті көшіріңіз (ол `AIza…` деп басталады). Оны құпиясөз сияқты құпия ұстаңыз.
4. SMTV-де: **Settings → AI → Your own key → Add a key** (Баптаулар → ЖИ → Өз кілтіңіз → Кілт қосу).
5. **Gemini** таңдап, кілтті қойып, **Check** (Тексеру) басыңыз. SMTV кілттің жұмыс істейтінін айтады.
6. Дайын. Енді ЖИ-дің әр қадамы Gemini-ді лайықты модельмен пайдаланады; қайсысы екенін **Settings → AI steps**
   (Баптаулар → ЖИ қадамдары) көрсетеді.

Басқа сервистер де дәл солай: тіркеліп, **API keys** табыңыз, кілт жасаңыз, оны SMTV-ге қойып, **Check** басыңыз.
Ақылы сервистер алдымен карта қосуды немесе балансты толтыруды сұрайды.

## Кілтіңіз қауіпсіз

- Компьютеріңізде шифрланып сақталады.
- Тек тиесілі сервисіне жіберіледі. StreamMoment оны ешқашан көрмейді.
- Жоғалттыңыз ба немесе ол тарап кетті ме? Оны сервис сайтында жойып, жаңасын жасаңыз.
