# Телефондағы SMTV

SMTV компьютеріңізде жұмыс істеп тұрғанда, телефоннан клиптерді көріңіз, сұрауларды іске қосыңыз және жұмысты
бақылаңыз. Телефонға ештеңе орнатудың қажеті жоқ: бәрі браузерде ашылады.

1. SMTV-де төменгі сол жақтағы **phone** (телефон) түймесін басыңыз.
2. **Open access from a phone** (Телефоннан кіруді ашу) қосыңыз.
3. Желі бірнеше ме? **Address in the network** (Желідегі мекенжай) ішінен телефоныңыз қосылған Wi-Fi желісінің
   мекенжайын таңдаңыз.
4. Телефон камерасын **QR-кодқа** бағыттап, сілтемені ашыңыз.

## Не білу керек

- Телефон компьютермен **бір Wi-Fi** желісінде болуы керек. Қонақ желілері көбіне құрылғыларды бір-бірінен бөледі,
  ал телефондағы немесе компьютердегі VPN кедергі келтіреді.
- Алғаш рет macOS немесе Windows SMTV-ге қосылымдарды қабылдауға рұқсат беру-бермеуді сұрайды: **рұқсат етіңіз**.
- Қосылым қарапайым, шифрлаусыз: оны **тек үйде** пайдаланыңыз, ешқашан қоғамдық Wi-Fi-да емес.
- Кодтың ішінде кілт бар; онсыз бет ашылмайды. Кіруді өшірсеңіз, барлық телефон ажыратылады, ал келесі жолы жаңа код
  жасалады.
- Телефонды пайдаланып жатқанда компьютер қосулы тұруы керек.
