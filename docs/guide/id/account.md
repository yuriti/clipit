# Akun StreamMoment

Cara paling mudah untuk memberi SMTV sebuah AI. Kamu masuk, mengisi saldo, dan SMTV memakai AI dari StreamMoment — tanpa
key, tanpa pengaturan. Akun ini juga mengambil **link** rekaman Twitch dan YouTube untuk SMTV.

## Masuk

1. Di SMTV buka **Settings → Account** (Pengaturan → Akun), atau tekan **Go to the account** (Ke akun) di Settings → AI.
2. Tekan **Sign in** (Masuk). Browser membuka halaman StreamMoment.
3. Masuk dengan **Google**, **Twitch**, atau **Telegram**.
4. Kembali ke SMTV: SMTV menampilkan «Signed in» (Sudah masuk) dengan sendirinya.

Browser tidak terbuka? Tekan **Sign in with a code** (Masuk dengan kode): SMTV menampilkan sebuah alamat dan kode; buka
alamat itu di perangkat mana pun dan ketik kodenya.

## Saldo

**Settings → Account** menampilkan saldo dan kira-kira cukup untuk berapa jam stream. **Buy** (Beli) membuka halaman
pembayaran di browser; saldo di SMTV diperbarui dengan sendirinya. Selama permintaan berjalan, SMTV menahan sedikit
saldo dan mengembalikan bagian yang tidak terpakai.

## Apa yang dilihat akun

- Klip dan file videomu tetap di komputermu.
- Untuk link, server StreamMoment mengambil rekaman dari platform dan meneruskannya ke SMTV sepotong demi sepotong; server
  tidak menyimpan apa pun.
- Teks stream dikirim lewat akun ke AI, untuk memilih momen.

## Keluar

**Settings → Account → Sign out on this computer** (Keluar di komputer ini). Saldo tetap tersimpan di akun.

Lebih suka tanpa akun? Pakai [key milikmu sendiri](get-a-key.md) atau [AI gratis di komputermu](free-ai-on-your-computer.md),
dan berikan file video ke SMTV, bukan link.
