# Обновление и удаление

## Обновление

SMTV раз в день проверяет, есть ли новая версия (это можно выключить). Когда она есть, он пишет **Доступна версия …**:
нажмите **Обновить**.

- SMTV закроется, обновится и снова откроется сам, обычно меньше чем за минуту.
- Если идёт запрос, обновление подождёт, пока он закончится, — или нажмите **Остановить задания и обновить**; потом
  **Продолжить** продолжит их с того же шага.
- Если новая версия не запускается, сама возвращается прежняя.
- Новые версии подписаны авторами SMTV; перед установкой SMTV проверяет подпись.

Всё об обновлениях — в **Настройки → Проверка компьютера → Обновления**.

Скачали SMTV для Windows или Mac? **Обновить** скачает новый установщик, проверит его и откроет: завершите установку в
нём (на Mac перетащите новый SMTV в «Программы» и нажмите **Заменить**). Копия для Windows из ZIP-архива сама не
обновляется: скачайте новый архив со [страницы выпуска](https://github.com/streammomenttv/smtv/releases/latest).

Поставили SMTV другим способом? В Docker новая версия — это новый образ; см. [для опытных пользователей](../advanced.md#docker).

## Удаление

**Настройки → Проверка компьютера → Удалить SMTV с компьютера** (кнопка **Удалить…**) удаляет программу и значок SMTV. Ваши клипы остаются — поставьте галочку
**Удалить и клипы, задания, настройки и ключи**, чтобы удалить и их.

Скачали SMTV для Windows или Mac? Саму программу удалите так, как принято в системе (кнопка выше удаляет только клипы
и настройки, если поставить галочку):

- **Windows:** **Параметры → Приложения → Установленные приложения → SMTV → Удалить**. Копию из ZIP-архива — просто
  удалите её папку.
- **Mac:** перетащите **SMTV** из **«Программ»** в **Корзину**.

Ставили одной строкой в терминале? Без окна, в терминале:

```bash
smtv uninstall
```

Добавьте `--data`, чтобы удалить и клипы с настройками. Программы, которые вы ставили сами (Ollama, LM Studio),
остаются: удаляйте их как любую другую программу.
