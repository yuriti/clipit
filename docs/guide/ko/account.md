# StreamMoment 계정

> 🕓 **곧 제공됩니다.** StreamMoment 계정 로그인은 아직 열리지 않았습니다. 그때까지 SMTV는 계정 없이도 모든 기능을 쓸 수 있습니다: [내 키](get-a-key.md) 또는 [컴퓨터의 무료 AI](free-ai-on-your-computer.md)를 사용하고, 링크는 **Download links myself** (Settings → VodCut)를 켜세요. 이 페이지는 계정이 열린 뒤의 사용법을 설명합니다.

SMTV에 AI를 연결하는 가장 간단한 방법입니다. 로그인하고 잔액을 충전하면 SMTV가 StreamMoment의 AI를 사용합니다 — 키도, 설정도 필요 없습니다.
계정은 SMTV를 위해 Twitch와 YouTube 녹화본 **링크**도 가져옵니다.

## 로그인

1. SMTV에서 **Settings → Account**(설정 → 계정)를 엽니다(또는 Settings → AI에서 **Go to the account**를 누릅니다).
2. **Sign in**(로그인)을 누릅니다. 브라우저에서 StreamMoment 페이지가 열립니다.
3. **Google**, **Twitch** 또는 **Telegram**으로 로그인합니다.
4. SMTV로 돌아오면 저절로 «Signed in»(로그인됨)이 표시됩니다.

브라우저가 열리지 않았나요? **Sign in with a code**(코드로 로그인)를 누르세요: SMTV가 주소와 코드를 보여 줍니다. 아무 기기에서나
그 주소를 열고 코드를 입력하면 됩니다.

## 잔액

**Settings → Account**에는 잔액과, 그 잔액으로 대략 몇 시간 분량의 방송을 처리할 수 있는지가 표시됩니다. **Buy**(구매)를 누르면
브라우저에서 결제 페이지가 열립니다. SMTV의 잔액은 저절로 갱신됩니다. 요청이 진행되는 동안 SMTV는 잔액에서 조금을 잡아 두고,
쓰지 않은 만큼은 돌려줍니다.

## 계정이 볼 수 있는 것

- 내 클립과 동영상 파일은 내 컴퓨터에 남습니다.
- 링크의 경우 StreamMoment 서버가 플랫폼에서 녹화본을 가져와 조각조각 SMTV로 넘겨 줍니다. 아무것도 저장하지 않습니다.
- 순간을 고르기 위해 방송의 텍스트가 계정을 거쳐 AI로 전달됩니다.

## 로그아웃

**Settings → Account → Sign out on this computer**(이 컴퓨터에서 로그아웃). 잔액은 계정에 그대로 남습니다.

계정을 쓰고 싶지 않나요? [내 키](get-a-key.md)나 [내 컴퓨터의 무료 AI](free-ai-on-your-computer.md)를 쓰고,
링크 대신 동영상 파일을 SMTV에 넣어 주세요.
