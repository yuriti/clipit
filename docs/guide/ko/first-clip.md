# 첫 클립

<img src="../../images/new-request.gif" alt="새 요청: 동영상 파일을 고르면 SMTV가 시작하고 모든 단계를 보여 줍니다" width="820">

## 1. AI 고르기(한 번만)

SMTV는 내 컴퓨터에서 방송의 음성을 텍스트로 바꾸고, AI가 그 텍스트를 읽어 순간을 고릅니다. 처음 실행하면 SMTV가 AI를 연결하는
세 가지 방법을 보여 줍니다. 가장 간단한 것은 StreamMoment 계정입니다. 잘 모르겠다면 [어떤 AI를 고를까](connect-ai.md)를 읽어 보세요.

## 2. SMTV에 방송 넣기

홈 화면(«What shall we cut into clips?»: "무엇을 클립으로 만들까요?")에서:

- **링크** — Twitch(`twitch.tv/videos/…`)나 YouTube 녹화본 링크를 붙여 넣습니다. 링크에는
  [StreamMoment 계정](account.md)이 필요합니다: 그 서버가 SMTV를 위해 녹화본을 가져오고 아무것도 남기지 않습니다.
- **파일** — 파일 버튼이나 **A file from this computer**(이 컴퓨터의 파일)를 누르고 동영상을 고릅니다. 파일은 계정이 필요 없고
  내 컴퓨터 밖으로 나가지 않습니다.

**Enter**나 화살표 버튼을 누릅니다.

## 3. 작동하는 모습 보기

요청은 목록 오른쪽에 열립니다. **Progress**(진행 상황)에 단계와 시간이 표시됩니다:

1. **Speech to text**(음성을 텍스트로) — 내 컴퓨터에서; 2시간짜리 방송은 몇 분 걸립니다.
2. **Finding moments**(순간 찾기)와 **rating**(평가) — AI가 텍스트를 읽습니다.
3. **Montage**(편집) — 클립마다 잘라 내고, 9:16으로 구도를 잡고, 자막과 타이틀 카드를 붙입니다.
4. **Recap**(요약) — 클립 다음에 방송 전체의 20–30분 영상을 만듭니다.

창을 닫아도 됩니다: SMTV가 백그라운드에서 계속할지 물어봅니다. **Pause**(일시 정지)는 작업을 멈추고, **Continue**(계속)는
같은 단계부터 다시 시작합니다.

## 4. 클립 받기

클립은 요약 영상 아래에 하나씩 나타납니다. 클립을 클릭하면 텍스트 옆에서 재생되고, SMTV가 왜 골랐는지 볼 수 있습니다.
다운로드 버튼으로 받아서 올리세요.

<img src="../../images/viewer.png" alt="자막 텍스트 옆에서 재생 중인 클립" width="820">

파일은 어디 있나요? 내 컴퓨터의 SMTV 전용 폴더에 있습니다. 다운로드 버튼을 누르면 원하는 곳에 사본을 저장합니다.

## 알아 두면 좋은 점

- 6–12시간 방송에서는 최대 30개의 클립이 나옵니다. 짧거나 조용한 방송은 몇 개만 나오거나 하나도 안 나올 수 있습니다:
  SMTV는 AI가 좋다고 평가한 순간만 남기기 때문입니다.
- 요청을 시작하기 전에 SMTV가 예상 소요 시간을 보여 줍니다.
- 뭔가 멈췄나요? [문제가 생겼어요](troubleshooting.md)를 보세요.
