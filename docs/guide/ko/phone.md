# 휴대폰에서 SMTV

SMTV가 컴퓨터에서 돌아가는 동안 휴대폰으로 클립을 보고, 요청을 시작하고, 작업을 지켜볼 수 있습니다. 휴대폰에는 설치할 것이 없습니다:
브라우저에서 열립니다.

1. SMTV에서 왼쪽 아래의 **휴대폰**(**phone**) 버튼을 누릅니다.
2. **Open access from a phone**(휴대폰에서 접속 허용)을 켭니다.
3. 네트워크가 여러 개인가요? **Address in the network**(네트워크 주소)에서 휴대폰이 연결된 Wi-Fi의 것을 고릅니다.
4. 휴대폰 카메라를 **QR 코드**에 대고 링크를 엽니다.

<img src="../../images/phone.png" alt="휴대폰 연결: 스캔할 QR 코드" width="820">

## 알아 둘 점

- 휴대폰은 컴퓨터와 **같은 Wi-Fi**에 있어야 합니다. 게스트 네트워크는 기기끼리 떼어 놓는 경우가 많고, 휴대폰이나 컴퓨터의 VPN도 방해가 됩니다.
- 처음에는 macOS나 Windows가 SMTV의 연결 수락을 허용할지 묻습니다: **허용**하세요.
- 연결은 암호화되지 않은 일반 연결입니다: **집에서만** 쓰고, 공용 Wi-Fi에서는 절대 쓰지 마세요.
- 코드에는 키가 들어 있어서, 그것 없이는 페이지가 열리지 않습니다. 접속을 끄면 모든 휴대폰의 연결이 끊기고, 다음번에는 새 코드가 만들어집니다.
- 휴대폰을 쓰는 동안 컴퓨터는 켜져 있어야 합니다.
