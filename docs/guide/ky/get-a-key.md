# Ачкычты кайдан алса болот

**Ачкыч** («API ачкычы») — SMTVге сиздин атыңыздан ЖИ кызматын колдонууга мүмкүнчүлүк берген узун сырсөз. Аны
катталгандан кийин кызматтын сайтынан аласыз. SMTV аны компьютериңизде гана сактайт жана ошол кызматка гана жөнөтөт;
ал логдордо да, көйгөй тууралуу отчеттордо да эч качан көрүнбөйт.

> Баалар жана акысыз тарифтер өзгөрөт. Бул жерде жазылгандар кызматтардын өз беттеринде **23.11.2026** текшерилген — баштоодон мурун кызматтын барагын текшериңиз.

SMTV ошондой эле xAI, Together, Fireworks, Qwen, Kimi, GLM, Cerebras жана OpenAI менен шайкеш каалаган даректи билет —
[тажрыйбалуу колдонуучуларга](../../advanced.md#ai-services-and-keys) барагын караңыз.

**Акысыз тарифтин чектөөлөрү бар.** Узун стрим көп суроо жөнөтөт; чекке жеткенде кызмат «too many requests»
(суроолор өтө көп) деп жооп берет, ал эми SMTV күтөт же токтойт. 6–12 сааттык стрим үчүн акылуу тариф же
[аккаунт](account.md) жакшыраак.

## Мисал: акысыз Gemini ачкычы кадам-кадамы менен

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) ачып, Google аккаунту менен кириңиз.
2. Сураса, шарттарды кабыл алыңыз.
3. **Create API key** басыңыз. Ачкычты көчүрүңүз (ал `AIza…` деп башталат). Аны сырсөз сыяктуу сыр сактаңыз.
4. SMTVде: **Settings → AI → Your own key → Add a key** (Жөндөөлөр → ЖИ → Өз ачкычыңыз → Ачкыч кошуу).
5. **Gemini** тандап, ачкычты коюп, **Check** (Текшерүү) басыңыз. SMTV ачкыч иштейби же жокпу, айтат.
6. Даяр. Эми ЖИнин ар бир кадамы Gemini'ни ылайыктуу модель менен колдонот; кайсынысы экенин **Settings → AI steps**
   (Жөндөөлөр → ЖИ кадамдары) көрсөтөт.

Башка кызматтар да ушундай: катталып, **API keys** табыңыз, ачкыч түзүңүз, аны SMTVге коюп, **Check** басыңыз. Акылуу
кызматтар адегенде карта кошууну же балансты толуктоону сурашат.

## Ачкычыңыз коопсуз

- Компьютериңизде шифрленип сакталат.
- Таандык кызматына гана жөнөтүлөт. StreamMoment аны эч качан көрбөйт.
- Жоготуп алдыңызбы же ал жайылып кеттиби? Аны кызматтын сайтында өчүрүп, жаңысын түзүңүз.
