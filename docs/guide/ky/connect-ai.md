# Кайсы ЖИни тандоо керек

SMTV кепти текстке өзү, компьютериңизде айландырат. Эң мыкты учурларды тандоо үчүн ал жасалма интеллекттен сурайт
(ЖИ — ChatGPT'нин негизиндегидей тил модели). **Settings → AI** (Жөндөөлөр → ЖИ) бөлүмүндө үч жолдун **бирин**
тандаңыз. Аны каалаган убакта өзгөртсөңүз болот.

<img src="../../images/ai.png" alt="Settings → AI: ЖИни туташтыруунун үч жолу" width="820">

| | ⭐ Аккаунт аркылуу | 🔑 Өз ачкычыңыз | 💻 Акысыз, компьютериңизде |
|---|---|---|---|
| Эмне кыласыз | Кирип, балансты толуктайсыз | Кызматтын сайтынан ачкыч алып, аны коёсуз | Ollama же LM Studio жана модель орнотосуз |
| Баасы | Баланстан колдонгонуңузча | Кызматтын баалары; айрымдарында акысыз тариф бар | Акысыз |
| Клиптин сапаты | Эң жакшы (күчтүү булут моделдери) | Тандаган моделге жараша | Алсызыраак |
| Компьютер | Каалаганы | Каалаганы | Кубаттуу видеокарта: 8–16 ГБ видеоэс |
| Twitch жана YouTube шилтемелери | Ооба | Аккаунт менен бирге гана (же файл) | Аккаунт менен бирге гана (же файл) |
| Колдонмо | [Аккаунт](account.md) | [Ачкычты кайдан алса болот](get-a-key.md) | [Компьютердеги акысыз ЖИ](free-ai-on-your-computer.md) |

**Ишенбей жатасызбы?** Аккаунтту алыңыз: эч нерсе жөндөөнүн кереги жок. Эч нерсе сарптагыңыз келбейт жана оюн
компьютериңиз барбы? Адегенде акысыз жолду сынап көрүңүз. OpenAI, Claude же Gemini үчүн төлөп жүрөсүзбү? Өз
ачкычыңызды колдонуңуз.

**Ачкыч деген эмне?** ЖИ кызматынын узун сырсөзү («API ачкычы»). Аны катталгандан кийин кызматтын сайты берет. SMTV аны
компьютериңизде гана сактайт жана ошол кызматка гана жөнөтөт.

**Стримим кайда барат?** Видео компьютериңизде калат. Тандалган ЖИге стримдин тексти гана жөнөтүлөт. Компьютердеги
акысыз ЖИ менен эч нерсе сыртка чыкпайт.

**Башка жолдор.** **Other ways** (Башка жолдор) бөлүмүндө SMTV ChatGPT (Codex) же Claude (Claude Code) жазылуусун да
колдоно алат. Биз муну сунуштабайбыз: бул кызматтардын эрежелери жазылууну башка программалардын колдонушуна тыюу
салышы мүмкүн.
