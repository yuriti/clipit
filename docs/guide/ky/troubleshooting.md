# Бир нерсе туура эмес болду

## 1. Компьютерди текшерүү → Оңдоо

**Settings → Computer check** (Жөндөөлөр → Компьютерди текшерүү) SMTVге керектүүнүн баарын карап, сап-сабы менен
эмне туура, эмне туура эмес экенин айтат. Көйгөйдүн жанында **Fix** (Оңдоо) баскычы бар: SMTV колунан келгенин өзү
орнотот же оңдойт жана эмне кылып жатканын көрсөтөт.

<img src="../../images/check.png" alt="Settings → Computer check: ар бир сап өз абалы жана Fix баскычы менен" width="820">

| Сапта жазылганы | Эмне кылуу керек |
|---|---|
| **Video (ffmpeg)** жок | **Fix** басыңыз: SMTV өзү колдонгон видео куралы ffmpeg'ти орнотот. |
| **Captions** (субтитрлер) иштебейт | **Fix** басыңыз: SMTV субтитр тарта алган ffmpeg орнотот. |
| **AI** (ЖИ): эч нерсе туташкан эмес | **Settings → AI** бөлүмүндө бирөөнү тандаңыз — [кайсынысын](connect-ai.md). |
| **Connection to StreamMoment** (StreamMoment менен байланыш) жок | Интернетти текшериңиз; аны VPN же брандмауэр бөгөттөшү мүмкүн. Файлдар ансыз да иштейт. |
| **Free space** (бош орун) аз | Дисктен орун бошотуңуз: 6 сааттык стрим иштетилип жатканда болжол менен 20 ГБ талап кылат. |
| **Speech to text** (кепти текстке айландыруу): модель жүктөлгөн эмес | Ал биринчи суроодо өзү жүктөлөт; же **Settings → Speech to text** ичинде **Download** басыңыз. |

Администратордун сырсөзүн талап кылган оңдоо эч качан үнсүз иштетилбейт: SMTV буйрук жазылган терминалды ачат, ошондо
анын эмне кылып жатканын көрөсүз.

## 2. Көп кездешкен көйгөйлөр

- **Шилтеме иштебейт.** Шилтемелер үчүн [StreamMoment аккаунту](account.md) керек. Аккаунт жокпу? Жазууну өзүңүз
  жүктөп алып, SMTVге файл бериңиз.
- **Клип жок же абдан аз.** SMTV ЖИ жакшы деп баалаган учурларды гана калтырат. Кыска же тынч стрим аз бериши мүмкүн.
  Компьютердеги акысыз ЖИ булуттагыга караганда жакшы учурларды азыраак табат.
- **«Too many requests»** (суроолор өтө көп). ЖИ кызматыңыздын акысыз тарифи чегине жетти: күтүңүз же акылуу тарифти
  же аккаунтту колдонуңуз.
- **Телефон SMTVни ачпайт.** Бир Wi-Fi, VPN жок, брандмауэрде SMTVге уруксат бериңиз — [телефон](phone.md) барагын
  караңыз.
- **Windows: терминал `smtv` иштетпейт.** Бул Smart App Control; SMTVни сөлөкөтүнөн иштетиңиз.
- **Терезе SMTV менен байланышын жоготту.** Терезени жаап, SMTVни кайра ачыңыз.

Токтоп калган суроону улантса болот: **Continue** (Улантуу) басыңыз — SMTV ошол эле кадамдан улантат жана жасалганды
кайра жасабайт.

## 3. Көйгөй тууралуу билдирүү

Дагы эле чечилбедиби? Бизге айтыңыз — бул баарына жардам берет.

1. **Settings → Computer check → Report a problem** (**Report…** баскычы; ал **Settings → About** ичинде да бар) же
   ийгиликсиз аяктаган суроонун астындагы баскыч.
2. SMTV отчетко эмне кирерин көрсөтөт: версиялар, компьютерди текшерүү, жөндөөлөр жана логдор. **Ачкычтар жана
   токендер кесилип алынат**, үй папкаңыз `~` болуп көрсөтүлөт. Белги койбосоңуз, шилтемелер жана файлдардын аттары
   отчетко кирбейт.
3. **Save and open GitHub** (Сактап, GitHub ачуу) басыңыз. SMTV архивди сактайт, ал эми браузерде кыскача мазмуну
   толтурулган жаңы issue ачылат. Архивди ага сүйрөп барып, **Submit** басыңыз.

SMTV өзүнөн-өзү эч нерсе жөнөтпөйт. Терезесиз: терминалда `smtv report` аткарыңыз. Ошондой эле түздөн-түз
[issue ачсаңыз](https://github.com/yuriti/clipit/issues/new?template=bug.yml) болот.
