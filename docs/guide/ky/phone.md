# Телефондогу SMTV

SMTV компьютериңизде иштеп турганда, телефондон клиптерди көрүңүз, суроолорду иштетиңиз жана ишти көзөмөлдөңүз.
Телефонго эч нерсе орнотуунун кереги жок: баары браузерде ачылат.

1. SMTVде төмөнкү сол жактагы **phone** (телефон) баскычын басыңыз.
2. **Open access from a phone** (Телефондон кирүүнү ачуу) күйгүзүңүз.
3. Тармак бир нечеби? **Address in the network** (Тармактагы дарек) ичинен телефонуңуз туташкан Wi-Fi тармагынын
   дарегин тандаңыз.
4. Телефондун камерасын **QR-кодго** багыттап, шилтемени ачыңыз.

## Эмнени билүү керек

- Телефон компьютер менен **бир Wi-Fi** тармагында болушу керек. Конок тармактары көбүнчө түзмөктөрдү бири-биринен
  бөлүп коёт, ал эми телефондогу же компьютердеги VPN тоскоол болот.
- Биринчи жолу macOS же Windows SMTVге туташууларды кабыл алууга уруксат берүү керекпи деп сурайт: **уруксат
  бериңиз**.
- Туташуу жөнөкөй, шифрлөөсүз: аны **үйдө гана** колдонуңуз, эч качан коомдук Wi-Fi'да эмес.
- Коддун ичинде ачкыч бар; ансыз барак ачылбайт. Кирүүнү өчүрсөңүз, бардык телефондор ажыратылат, ал эми кийинки
  жолу жаңы код түзүлөт.
- Телефонду колдонуп жатканда компьютер күйүк турушу керек.
