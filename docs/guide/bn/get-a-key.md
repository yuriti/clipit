# চাবি কোথায় পাবেন

**চাবি** (একটা «API key») হলো একটা লম্বা পাসওয়ার্ড, যা দিয়ে SMTV আপনার হয়ে কোনো AI সার্ভিস ব্যবহার করতে পারে। সাইন আপ
করার পর সার্ভিসের সাইটে এটা পাবেন। SMTV এটা শুধু আপনার কম্পিউটারে রাখে আর শুধু সেই সার্ভিসকেই পাঠায়; এটা কখনো লগ বা
সমস্যার রিপোর্টে দেখা যায় না।

> দাম আর ফ্রি প্ল্যান বদলায়। এখানে যা লেখা আছে তা সার্ভিসগুলোর নিজেদের পেজে **23.11.2026** তারিখে মিলিয়ে দেখা হয়েছে — শুরু করার আগে সার্ভিসের পেজ দেখে নিন।

## উদাহরণ: বিনামূল্যের Gemini চাবি, ধাপে ধাপে

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) খুলুন আর একটা Google অ্যাকাউন্ট দিয়ে সাইন ইন করুন।
2. জিজ্ঞেস করলে শর্তাবলি মেনে নিন।
3. **Create API key** চাপুন। চাবিটা কপি করুন (এটা `AIza…` দিয়ে শুরু হয়)। পাসওয়ার্ডের মতো গোপন রাখুন।
4. SMTV-তে: **Settings → AI → Your own key → Add a key** (সেটিংস → AI → আপনার নিজের চাবি → চাবি যোগ করুন)।
5. **Gemini** বেছে নিন, চাবি পেস্ট করুন, **Check** (যাচাই) চাপুন। SMTV জানায় চাবিটা কাজ করছে কি না।
6. হয়ে গেল। AI-এর প্রতিটা ধাপ এখন উপযুক্ত মডেল সহ Gemini ব্যবহার করে; **Settings → AI steps** (AI-এর ধাপ) দেখায়
   কোনটা।

অন্য সার্ভিসগুলোও একইভাবে কাজ করে: সাইন আপ করুন, **API keys** খুঁজুন, একটা তৈরি করুন, SMTV-তে পেস্ট করুন, **Check**
চাপুন। পেইড সার্ভিস আগে কার্ড যোগ করতে বা ব্যালান্স টপ আপ করতে বলে।

## আপনার চাবি নিরাপদ

- আপনার কম্পিউটারে এনক্রিপ্ট করে রাখা হয়।
- শুধু যে সার্ভিসের চাবি সেখানেই পাঠানো হয়। StreamMoment এটা কখনো দেখে না।
- হারিয়ে গেছে বা ফাঁস হয়ে গেছে? সার্ভিসের সাইটে সেটা মুছে একটা নতুন তৈরি করুন।
