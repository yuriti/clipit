# ফোনে SMTV

SMTV আপনার কম্পিউটারে চলার সময় ফোন থেকে ক্লিপ দেখুন, রিকোয়েস্ট শুরু করুন আর কাজের ওপর নজর রাখুন। ফোনে কিছু ইনস্টল
করতে হবে না: এটা ব্রাউজারে খোলে।

1. SMTV-তে নিচে বাঁ দিকে **ফোন** বোতাম চাপুন।
2. **Open access from a phone** (ফোন থেকে অ্যাক্সেস খুলুন) চালু করুন।
3. একাধিক নেটওয়ার্ক? **Address in the network** (নেটওয়ার্কে ঠিকানা)-তে সেই Wi-Fi-এরটা বেছে নিন যেটায় আপনার ফোন আছে।
4. ফোনের ক্যামেরা **QR কোডের** দিকে ধরুন আর লিংকটা খুলুন।

## যা জানা দরকার

- ফোনকে কম্পিউটারের **একই Wi-Fi**-তে থাকতে হবে। গেস্ট নেটওয়ার্ক প্রায়ই ডিভাইসগুলোকে আলাদা রাখে, আর ফোন বা কম্পিউটারে
  VPN বাধা দেয়।
- প্রথমবার macOS বা Windows জিজ্ঞেস করে SMTV সংযোগ গ্রহণ করতে পারবে কি না: **অনুমতি দিন**।
- সংযোগটা সাধারণ, এনক্রিপশন ছাড়া: এটা **শুধু বাড়িতে** ব্যবহার করুন, পাবলিক Wi-Fi-তে কখনো নয়।
- কোডে একটা চাবি থাকে; সেটা ছাড়া পেজ খোলে না। অ্যাক্সেস বন্ধ করলে সব ফোনের সংযোগ কেটে যায়, আর পরের বার নতুন কোড তৈরি
  হয়।
- ফোন ব্যবহার করার সময় কম্পিউটার চালু রাখতে হবে।
