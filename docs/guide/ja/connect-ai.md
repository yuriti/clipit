# どの AI を選ぶか

SMTV は音声の文字起こしを、あなたのパソコンで自分で行います。見どころを選ぶときは AI（ChatGPT の中で動いているような言語モデル）に尋ねます。
**Settings → AI**（設定 → AI）で 3 つの方法から**ひとつ**選んでください。いつでも変更できます。

<img src="../../images/ai.png" alt="Settings → AI：AI をつなぐ 3 つの方法" width="820">

| | ⭐ アカウント経由 | 🔑 自分のキー | 💻 無料、自分のパソコンで |
|---|---|---|---|
| やること | サインインして残高をチャージ | サービスのサイトでキーを取得して貼り付け | Ollama または LM Studio とモデルをインストール |
| 費用 | 残高から使った分だけ | そのサービスの料金。無料プランがあるものも | 無料 |
| クリップの質 | 最高（強力なクラウドモデル） | 選んだモデル次第 | やや落ちる |
| パソコン | どれでも | どれでも | 高性能なグラフィックボード：ビデオメモリ 8〜16 GB |
| Twitch や YouTube のリンク | 使える | アカウントも必要（またはファイル） | アカウントも必要（またはファイル） |
| ガイド | [アカウント](account.md) | [キーの入手先](get-a-key.md) | [パソコンで動く無料 AI](free-ai-on-your-computer.md) |

**迷ったら？** アカウントにしてください：設定は何もいりません。お金をかけたくなくて、ゲーミング PC を持っている？まずは無料の方法を試してみてください。
すでに OpenAI、Claude、Gemini にお金を払っている？そのキーを使いましょう。

**キーって何？** AI サービス用の長いパスワード（「API キー」）です。サービスに登録すると、そのサイトで発行されます。
SMTV はそれをあなたのパソコンにだけ保存し、そのサービスにだけ送ります。

**配信はどこへ行くの？** 動画はあなたのパソコンに残ります。あなたが選んだ AI に送られるのは配信のテキストだけです。
パソコン上の無料 AI なら、何も外に出ません。

**その他の方法。** **Other ways**（その他の方法）では、ChatGPT（Codex）や Claude（Claude Code）のサブスクリプションも使えます。
おすすめはしません：これらのサービスの規約では、ほかのプログラムがサブスクリプションを使うことが禁止されている場合があります。
