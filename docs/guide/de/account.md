# Das StreamMoment-Konto

> 🕓 **Demnächst.** Die Anmeldung bei einem StreamMoment-Konto ist noch nicht geöffnet. Bis dahin funktioniert SMTV vollständig ohne Konto: Nutze [deinen eigenen Schlüssel](get-a-key.md) oder [eine kostenlose KI auf deinem Computer](free-ai-on-your-computer.md), und schalte für Links **Download links myself** (Settings → VodCut) ein. Diese Seite beschreibt, wie das Konto funktionieren wird, sobald es öffnet.

Der einfachste Weg, SMTV eine KI zu geben. Du meldest dich an, lädst das Guthaben auf, und SMTV nutzt die KI von
StreamMoment – keine Schlüssel, keine Einrichtung. Das Konto ruft für SMTV auch **Links** zu Twitch- und
YouTube-Aufnahmen ab.

## Anmelden

1. Öffne in SMTV **Settings → Account** (Einstellungen → Konto) oder drücke **Go to the account** in Settings → AI.
2. Drücke **Sign in** (Anmelden). Der Browser öffnet die Seite von StreamMoment.
3. Melde dich mit **Google**, **Twitch** oder **Telegram** an.
4. Geh zurück zu SMTV: Es zeigt von selbst «Signed in» (Angemeldet).

Der Browser hat sich nicht geöffnet? Drücke **Sign in with a code** (Mit Code anmelden): SMTV zeigt eine Adresse und
einen Code; öffne die Adresse auf einem beliebigen Gerät und gib den Code ein.

## Guthaben

**Settings → Account** zeigt das Guthaben und ungefähr, für wie viele Stunden Stream es reicht. **Buy** (Kaufen)
öffnet die Zahlungsseite im Browser; das Guthaben in SMTV aktualisiert sich von selbst. Während ein Auftrag läuft,
reserviert SMTV einen kleinen Betrag vom Guthaben und gibt zurück, was nicht verbraucht wurde.

## Was das Konto sieht

- Deine Clips und Videodateien bleiben auf deinem Computer.
- Bei einem Link holt der Server von StreamMoment die Aufnahme von der Plattform und reicht sie in Stücken an SMTV
  weiter; er speichert nichts.
- Der Text des Streams geht über das Konto an die KI, um die Momente auszuwählen.

## Abmelden

**Settings → Account → Sign out on this computer** (Auf diesem Computer abmelden). Das Guthaben bleibt beim Konto.

Lieber ohne Konto? Nutze [deinen eigenen Schlüssel](get-a-key.md) oder [eine kostenlose KI auf deinem Computer](free-ai-on-your-computer.md),
und gib SMTV Videodateien statt Links.
