# SMTV auf dem Handy

Sieh dir die Clips an, starte Aufträge und verfolge die Arbeit auf dem Handy, während SMTV auf deinem Computer läuft.
Auf dem Handy musst du nichts installieren: Es öffnet sich im Browser.

1. Drücke in SMTV den **Handy**-Knopf unten links.
2. Schalte **Open access from a phone** (Zugriff vom Handy erlauben) ein.
3. Mehrere Netzwerke? Wähle unter **Address in the network** (Adresse im Netzwerk) das des WLANs, in dem dein Handy ist.
4. Richte die Kamera des Handys auf den **QR-Code** und öffne den Link.

<img src="../../images/phone.png" alt="Ein Handy verbinden: ein QR-Code zum Scannen" width="820">

## Was du wissen solltest

- Das Handy muss im **selben WLAN** sein wie der Computer. Gastnetzwerke trennen Geräte oft voneinander, und ein VPN auf
  dem Handy oder dem Computer stört.
- Beim ersten Mal fragt macOS oder Windows, ob SMTV Verbindungen annehmen darf: **erlaube** es.
- Die Verbindung ist einfach, ohne Verschlüsselung: Nutze sie **nur zu Hause**, nie in einem öffentlichen WLAN.
- Der Code enthält einen Schlüssel; ohne ihn öffnet sich die Seite nicht. Schaltest du den Zugriff aus, werden alle
  Handys getrennt, und beim nächsten Mal wird ein neuer Code erstellt.
- Der Computer muss eingeschaltet bleiben, während du das Handy nutzt.
