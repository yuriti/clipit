# O SMTV no seu celular

Assista aos clipes, comece pedidos e acompanhe o trabalho pelo celular, enquanto o SMTV roda no seu computador. Não
precisa instalar nada no celular: ele abre no navegador.

1. No SMTV, clique no botão do **celular** no canto inferior esquerdo.
2. Ligue **Open access from a phone** (abrir acesso pelo celular).
3. Várias redes? Em **Address in the network** (endereço na rede), escolha a do Wi-Fi em que o seu celular está.
4. Aponte a câmera do celular para o **QR code** e abra o link.

<img src="../../images/phone.png" alt="Conectar um celular: um QR code para escanear" width="820">

## O que saber

- O celular precisa estar no **mesmo Wi-Fi** que o computador. Redes de convidados costumam separar os aparelhos, e
  uma VPN no celular ou no computador atrapalha.
- Na primeira vez, o macOS ou o Windows pergunta se o SMTV pode aceitar conexões: **permita**.
- A conexão é simples, sem criptografia: use **só em casa**, nunca em Wi-Fi público.
- O código guarda uma chave; sem ela a página não abre. Desligar o acesso desconecta todos os celulares, e um código
  novo é criado na próxima vez.
- O computador precisa ficar ligado enquanto você usa o celular.
